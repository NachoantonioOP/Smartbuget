# SmartBudget

SmartBudget es un proyecto de maquetación web avanzada enfocado en la gestión de finanzas personales. El objetivo principal fue construir una interfaz robusta y escalable utilizando estándares modernos de desarrollo Front-end.

## 🛠️ Tecnologías y Metodologías

* **HTML5 Semántico:** Estructura de contenido clara y accesible. 
* **SASS (Patrón 7-1):** Organización modular de hojas de estilo (Variables, Mixins, Base, Layout). 
* **Metodología BEM:** Uso de *Block-Element-Modifier* para un CSS mantenible y legible. 
* **Bootstrap 4:** Integración de componentes y sistema de grilla para acelerar el desarrollo. 
* **Flexbox & Media Queries:** Diseño responsivo personalizado para una visualización óptima en móviles y escritorio. 

## 🚀 Características Técnicas

* **Arquitectura Modular:** El proyecto utiliza un archivo `main.scss` que centraliza las importaciones de módulos específicos, facilitando el mantenimiento a largo plazo.
* **Componentes Reutilizables:** Se han creado clases CSS siguiendo BEM (ej. `.features__card`, `.hero__title`) para desacoplar el diseño de la estructura HTML. 
* [cite_start]**Compilación de Estilos:** Flujo de trabajo optimizado para transformar SASS en CSS ejecutable. 
* **Diseño UI:** Interfaz limpia con una sección Hero impactante, tarjetas de características y ventanas modales interactivas.

## 📦 Cómo ejecutar el proyecto

1.  Clona el repositorio:
    ```bash
    git clone [https://github.com/NachoantonioOP/Smartbuget.git](https://github.com/NachoantonioOP/Smartbuget.git)
    ```
2.  Para realizar cambios en los estilos, compila el SASS: 
    ```bash
    sass sass/main.scss css/style.css
    ```
3.  Abre `index.html` en tu navegador para ver el resultado.
